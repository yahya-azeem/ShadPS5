# ShadPS5 — High-Level PlayStation 5 Emulator Base

ShadPS5 is a cross-platform, high-level emulator (compatibility layer) for the PlayStation 5 (Prospero OS), written in **Rust**. It maps FreeBSD 11 kernel system calls and translates Agile Graphics Command (AGC) PM4 packet streams directly to Vulkan API calls on host desktop environments (Windows and Linux).

The project is structured with a modular, pure-Rust core using **SDL2** for cross-platform windowing, event management, and input, and **ash** for direct, low-overhead Vulkan bindings.

---


## 🛠️ Architecture Overview

The compatibility layer operates by virtualizing the CPU execution environment and translating guest calls rather than emulating CPU registers in software (an operation made obsolete by modern consoles using standard x86-64 Zen 2 architecture):

```
+--------------------------------------------------------+
|             PS5 Executable (.elf / .self)              |
+--------------------------------------------------------+
                            |
                            v
+--------------------------------------------------------+
|           ShadPS5 ELF Loader & Linker Subsystem         |
|  - Maps program segments                               |
|  - Cryptographic Name Identifier (NID) resolver        |
+--------------------------------------------------------+
        |                                        |
        v (System Calls)                         v (GPU command ring buffers)
+-------------------------------+      +---------------------------------+
|   Kernel Virtualization       |      |   Graphics Translation Layer    |
|  - FreeBSD 11 ABI Mapping     |      |  - Intercepts PM4 packets       |
|  - mmap -> Win32/Linux pages  |      |  - Translates AGC -> Vulkan     |
+-------------------------------+      +---------------------------------+
        |                                        |
        v                                        v
+-------------------------------+      +---------------------------------+
|      Host OS (Win32/Linux)    |      |         Vulkan 1.3 / GPU        |
+-------------------------------+      +---------------------------------+
```

### 1. Loader & Linker (`src/loader.rs`)
- Parses program headers of guest `.elf` or decrypted `.self` files.
- Simulates the dynamic linker by parsing **Name Identifiers (NIDs)**. Unlike standard ELFs that use human-readable strings like `malloc`, Prospero OS uses truncated cryptographic hashes to hide exports. The loader binds these NIDs to custom host-native function wrappers.

### 2. Kernel Virtualization (`src/kernel.rs`)
- Intercepts software interrupts (syscalls) generated by the game engine.
- Maps FreeBSD 11 system call numbers to host equivalents.
- Dynamically allocates page-aligned, virtual memory on the host using `VirtualAlloc` (Windows) and `mmap` (Linux) to simulate the 16 GB unified address block.

### 3. Graphics translation (`src/graphics.rs`)
- Decodes AMD PM4 packets sent to GPU ring buffers.
- Manages Vulkan physical/logical devices, queues, and presentation pipelines using SDL2.

## 🚀 Building & Running

ShadPS5 does not require Visual Studio or Qt, compiling fully via the standard Rust toolchain.

### Prerequisites

#### 1. Vulkan SDK
- **Windows**: Install using `winget` (already configured during repository initialization):
  ```powershell
  winget install --id KhronosGroup.VulkanSDK --accept-source-agreements --accept-package-agreements
  ```
- **Linux**: Install via package manager:
  - Ubuntu/Debian: `sudo apt install libvulkan-dev vulkan-tools`
  - Arch Linux: `sudo pacman -S vulkan-devel`

#### 2. SDL2 Development Libraries
- **Windows**: The build system is configured to download, bundle, and statically link SDL2 automatically via Cargo features. No manual steps are required.
- **Linux**: Install via package manager:
  - Ubuntu/Debian: `sudo apt install libsdl2-dev`
  - Arch Linux: `sudo pacman -S sdl2`

---

### 💻 Compilation

From the root of the workspace, build the executable using Cargo:

```bash
# Debug build
cargo build

# Release build (Optimized performance)
cargo build --release
```

---

### 🎯 Running the Emulator

Run the emulator and pass the path of a decrypted PS5 executable (.elf or .self):

```bash
cargo run -- <path_to_ps5_game_binary.elf>
```

#### Logs Output
You can configure log verbosity by setting the `RUST_LOG` environment variable:
```bash
# Windows (PowerShell)
$env:RUST_LOG="info"
cargo run

# Linux
RUST_LOG=info cargo run
```
